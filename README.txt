AI-OPTIMIZED CPU ARCHITECTURE - 3D MODEL
=========================================
Files:
1. AI_Optimized_CPU.obj  -> actual 3D geometry
2. AI_Optimized_CPU.mtl  -> component materials/colors
3. AI_Optimized_CPU_3D_Viewer.html -> browser viewer

The OBJ can be opened in Blender, SketchUp (with importer), MeshLab,
Windows 3D Viewer, or most online OBJ viewers.

The model contains:
- CPU package and die
- 5 CPU cores
- Cache
- ALU
- Control Unit
- FPU
- NPU (Neural Processing Unit)
- AI Optimization Unit
- I/O and power blocks

The raised AI and NPU blocks make the model suitable for a
Computer Architecture & Organization presentation.
